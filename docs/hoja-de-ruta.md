# Hoja de ruta

## Fase 1 (actual): sistema en Claude Code
Conversación + skills + kit + scripts. Objetivo: entregar webs reales con calidad y medir dónde se
pierde tiempo.

## Fase 2 (cuando haya 5–10 webs entregadas)
Construir solo lo que esos proyectos demuestren útil. Candidatos, por orden probable de valor:

| Función | Valor | Coste |
|---|---|---|
| Módulo de formulario de contacto/presupuesto (reutiliza la base de reservas) | Alto: casi todas las webs | Bajo |
| Módulo de carta editable por el cliente | Alto para restaurantes | Medio |
| Plantilla de propuesta para compartir con el cliente final (enlace privado) | Alto en ventas | Bajo |
| Panel interno de proyectos (estado de cada cliente desde PROYECTO.md) | Medio | Medio |
| Despliegue asistido a Hostinger (conector o API) | Medio | Medio, con riesgo |
| Módulo de citas | Según clientes | Alto |
| Interfaz propia (web) para iniciar proyectos y comparar propuestas | Bajo hasta tener volumen | Alto |

## Regla
Cada función nueva debe justificar su coste de desarrollo y mantenimiento con un caso real.
